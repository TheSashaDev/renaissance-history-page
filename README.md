# Renaissance Ideas — History Page

Interactive static page about Renaissance ideas and history, built as a visual frontend experiment.

## Tech

- HTML/CSS/JavaScript
- GSAP animations
- Lenis smooth scrolling
- Google Fonts

## Run locally

Open `index.html` in a browser or serve it with:

```bash
python3 -m http.server 8000
```

## Deployment

Can be hosted on GitHub Pages as a static site.
